kx · arquitetura

Do arquivo salvo à resposta do agente. Tudo local.

Um binário compartilhado, um índice SQLite por projeto. O MCP lê e escreve; o CLI só lê. WAL permite os dois ao mesmo tempo.

03 · Índice por projeto

Um arquivo SQLite

~/.kx/data/{projeto}.sqlite

sqlite-vec + FTS5 no mesmo banco, modo WAL. Nada é compartilhado entre projetos.

projeto-a.sqlite .kx.json projeto-b.sqlite .kx.json projeto-c.sqlite .kx.json
